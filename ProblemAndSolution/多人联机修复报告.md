# Tcamp_FPS 多人联机武器系统修复报告

---

## 问题一：第二玩家无法换枪、无法射击

### 问题描述
多人联机（Listen Server）模式下，二号玩家（P2）无法切换武器、无法开火射击，控制台报错。

### 问题分析
整个武器操作链路完全在客户端本地执行，没有任何网络 RPC 通信：

```
客户端输入 → DoStartFiring() → WeaponInventory::StartFiring() 
→ Weapon::StartFiring() → Fire() → FireProjectile() → 本地生成弹丸
```

服务端从未收到开火请求，弹丸只在客户端生成，其他玩家看不到也无法受到伤害。换枪链路同理——`SwitchWeapon()` 只在本地切换，服务端 `CurrentWeapon` 从未改变。

此外，`AShooterWeapon::CurrentBullets`（弹量）不是复制属性，`AShooterProjectile` 的伤害值也不是复制属性——即使弹丸偶然到达客户端，伤害值也是默认值。

### 解决方案

**架构：服务端权威（Server-Authoritative）**

| 层级 | 职责 |
|------|------|
| 客户端 | 通过 `Server` RPC 发送输入意图 |
| 服务端 | 验证、执行射击/生成弹丸、管理弹药 |
| 属性复制 | 同步 `CurrentBullets`、`CurrentWeapon`、弹丸伤害属性 |
| 多播 RPC | 动画、后坐力、受击特效到所有客户端 |

**修改的 12 个文件：**

1. **AShooterProjectile** —— `HitDamage`/`WeaponHeadshotMultiplier`/`MaxPenetrations`/`PenetrationDamageFalloff` 加 `Replicated`；`NotifyHit` 服务端专用（`HasAuthority()` 守卫）；新增 `MulticastOnHit` RPC 推送受击特效到所有客户端
2. **AShooterWeapon** —— `CurrentBullets` 改为 `ReplicatedUsing`；`FireProjectile` 服务端生成弹丸；新增 `MulticastFireEffects` RPC 推送动画/后坐力；新增 `ConfigureProjectile` 虚函数让子类设置伤害属性
3. **ATacticalWeapon** —— 用 `ConfigureProjectile` 替换 `FireProjectile` 重写
4. **UWeaponInventoryComponent** —— 新增 `ServerStartFiring`/`ServerStopFiring`/`ServerSwitchWeapon`/`ServerSwitchToCategory` RPC；公开 API 自动路由到服务端；`AddWeapon` 加权限检查；新增 `bCanFire` 安全门；`OnRep_CurrentWeapon` 用 `CachedCurrentWeapon` 正确追踪旧武器
5. **AShooterCharacter** —— 死亡时设置 `bCanFire = false`
6. **ATacticalCharacter** —— `bFrozen` 加复制和 `OnRep_Frozen`；冻结/解冻同步 `bCanFire`
7. **AShooterNPC** —— 武器生成和射击加 `HasAuthority()` 守卫

## 问题二：远程客户端第一人称动画蓝图崩溃

### 问题描述
蓝图运行时错误：`ABP_FP_Pistol` / `ABP_FP_Weapon` EventGraph 中 `GetController()` 返回 None，访问空指针崩溃。

### 问题分析
武器复制系统修复后，`OnRep_CurrentWeapon` → `OnWeaponChanged` 在远程客户端正确触发，进而设置第一人称动画蓝图。但远程客户端角色是模拟代理（Simulated Proxy），没有 PlayerController，`GetController()` 返回 None。

此外，角色和武器的第一人称网格体默认就是 `bOnlyOwnerSee = true`（只对拥有者可见），远程客户端上根本不渲染，运行完整 ABP 毫无意义。

### 解决方案
在角色和武器的初始化阶段，非本地控制端直接清空第一人称网格体的动画实例：

- `ATcamp_FPSCharacter::BeginPlay` —— `!IsLocallyControlled()` 时 `SetAnimInstanceClass(nullptr)`
- `AShooterWeapon::BeginPlay` —— `!PawnOwner->IsLocallyControlled()` 时 `SetAnimInstanceClass(nullptr)`
- `AShooterCharacter::OnWeaponChanged` / `OnWeaponActivated` —— `IsLocallyControlled()` 守卫保护 1P ABP 设置

## 问题三：OnRep 回调在 BeginPlay 之前触发导致空指针崩溃

### 问题描述
`AShooterWeapon::OnRep_CurrentBullets` 崩溃，访问 `WeaponOwner` 空指针。

### 问题分析
UE 属性复制回调 `OnRep_CurrentBullets` 在 Actor `BeginPlay` **之前**触发。此时 `WeaponOwner` 还未初始化（`WeaponOwner` 在 `BeginPlay` 中通过 `Cast<IShooterWeaponHolder>(GetOwner())` 设置）。

### 解决方案
所有访问 `WeaponOwner` 的地方加空指针守卫：

- `OnRep_CurrentBullets` —— `if (WeaponOwner)` 
- `MulticastFireEffects_Implementation` —— `if (!WeaponOwner) return`
- `FireProjectile` —— `if (WeaponOwner)`
- `BeginPlay` —— `GetOwner()` 判空后再绑定 `OnDestroyed`

## 问题四：远程客户端子弹/血量 UI 不显示

### 问题描述
P2 客户端拿枪后弹药 UI 始终空白，血量一直显示满血，但 P1 正常。

### 问题分析
多层时序问题叠加：

1. **`OnRep_CurrentBullets`** 在武器 `BeginPlay` 前触发 → `WeaponOwner` 为空 → 弹量更新丢失
2. **`OnRep_CurrentWeapon`** 在角色 `BeginPlay` 前触发 → `OnWeaponChanged` 未绑定 → 弹量广播丢失
3. **所有 `OnRep_*`** 在 `OnPossess` 前触发 → PlayerController 未绑定代理 → UI 收不到初始数据
4. **Widget 创建方式问题**：`AddToViewport` 在 PIE 多玩家模式下只添加到主视口，P2 独立窗口收不到。改用 `AddToPlayerScreen`（通过 `LocalPlayer->ViewportClient` 正确路由）

### 解决方案

**时序补偿（三层互补）：**
- `AShooterWeapon::BeginPlay` 末尾主动广播弹量（补偿 `OnRep_CurrentBullets` 太早）
- `AShooterCharacter::BeginPlay` 手动触发 `OnWeaponChanged`（补偿 `OnRep_CurrentWeapon` 太早）
- `AShooterPlayerController::OnPossess` 主动拉取当前血量/弹量（补偿 `OnRep_*` 在绑定前触发）

**Widget 创建移入 `OnPossess`：**
- Widget 懒加载创建放到 `OnPossess` 开头，确保代理绑定前 Widget 一定存在
- `AddToPlayerScreen` 替换 `AddToViewport`，正确路由到本地玩家视口

## 问题五：远程客户端看不到物理对象移动

### 问题描述
P1 射击箱子后箱子移动，但 P2 视角里箱子不动。

### 问题分析
`NotifyHit` 改为服务端权威后，物理冲量只在服务端施加。关卡中放置的 `StaticMeshActor` 默认不复制移动，客户端无法看到物理位移。

`SetReplicateMovement(true)` 对运行时动态开启复制的关卡静态 Actor 不生效。

### 解决方案
创建专用 `AReplicatedPhysicsActor` 类：

- 构造函数即设置 `bReplicates = true` + `SetReplicateMovement(true)`
- 网格体组件 `SetIsReplicated(true)`
- 替换关卡中需要物理反应的对象（箱子、油桶等）
